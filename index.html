This asks Claude to fetch skill files from GitHub as needed, so it needs a claude.ai plan with web fetching enabled. If it doesn't work, copy this SKILL.md link into a new chat yourself and ask Claude to follow it.

This opens with whatever model your account defaults to, often Opus. None of these skills need it; switch to Sonnet 5 in the model picker once the chat opens for a faster, cheaper run.

Working Backwards PR/FAQ is the natural entry point: it clarifies what you're building and why before anything else. From there, the other skills pick up the thread: breaking the idea into use cases, writing each one out, generating test cases, and deriving trackable requirements you can export to Jira or GitHub Issues. Once there's enough to work with, Architect Review turns it into a structured build recommendation.

  • Clean Style: an anti-AI-slop checklist every other skill's output defers to.
  • Working Backwards PR/FAQ: press release, FAQ, and business case for a new idea.
  • Use Case Discovery: breaks a feature down into a candidate list of use cases.
  • Use Case UML: writes a use case in a fixed, repeatable format.
  • Use Case Test Cases: generates test cases from a use case's paths.
  • Use Case Requirements: derives trackable requirements, with or without a use case.
  • Architect Review: a structured architecture recommendation from a specific Sr. Architect persona.
