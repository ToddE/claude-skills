Claude Skills

Eight skills for Claude AI: a writing baseline, a PR/FAQ generator, a full use-case-to-tracker-issue pipeline, a standalone use case builder, and architecture recommendations.

Start with a product idea.

Click below to open a new claude.ai chat, pre-loaded with the whole planning flow: Working Backwards PR/FAQ first, then use case discovery, use case writing, test cases, and requirements, as the conversation gets there. Uses your own claude.ai account and session.

Get started in claude.ai →

This asks Claude to fetch skill files from GitHub as needed, so it needs a claude.ai plan with web fetching enabled. If it doesn't work, copy this SKILL.md link into a new chat yourself and ask Claude to follow it.

This opens with whatever model your account defaults to, often Opus. Switch to Sonnet 5 in the model picker once the chat opens for a faster, cheaper run.

Working Backwards PR/FAQ is the natural entry point: it clarifies what you're building and why before anything else. From there, the other skills pick up the thread: breaking the idea into use cases, writing each one out, generating test cases, and deriving trackable requirements you can export to Jira or GitHub Issues. Once there's enough to work with, Architect Review turns it into a structured build recommendation.

Use one skill on its own

Each pipeline skill also works by itself. When you start mid-pipeline, the skill asks for what it needs instead of requiring the earlier steps. Use Try in claude.ai to open a chat with just that skill loaded, or download its .skill file to install it.

  • Working Backwards PR/FAQ: Press release, FAQ, and business case for a new idea. Start with a rough idea.
    Try in claude.ai · Download .skill · Source
  • Use Case Discovery: Breaks a feature down into a list of candidate use cases to review before writing any in full. Start with a feature description.
    Try in claude.ai · Download .skill · Source
  • Use Case UML: Writes one use case in a fixed format: actors, basic path, alternate and exception paths, post-conditions. Start with a flow you want documented.
    Try in claude.ai · Download .skill · Source
  • Use Case Test Cases: Generates test cases from a use case's paths and post-conditions. Start with a use case, or a flow it can write one from.
    Try in claude.ai · Download .skill · Source
  • Use Case Requirements: Derives trackable requirements and exports them as Jira CSV or GitHub Issues. Start with a use case, or just a feature description.
    Try in claude.ai · Download .skill · Source
  • Architect Review: A structured architecture recommendation from a specific Sr. Architect persona. Start with whatever you have: a PR/FAQ, use cases, or a description.
    Try in claude.ai · Download .skill · Source
  • Build Plan: Turns the use cases, requirements, and test cases into an implementation plan for claude-build: BUILD_STATE.md, CLAUDE.md, claude-build.conf, a build plan, and an engineering prompt. Start with requirements and an architecture, or a description.
    Try in claude.ai · Download .skill · Source

Other skills

  • Use Case Builder: Use Case Discovery and Use Case UML in one skill: scopes a feature into use cases, then writes each one in full. Start with a feature description.
    Try in claude.ai · Download .skill · Source
  • Clean Style: An anti-AI-slop checklist for external-facing writing. The other skills use it when it's installed. Start with a draft to clean up.
    Try in claude.ai · Download .skill · Source
