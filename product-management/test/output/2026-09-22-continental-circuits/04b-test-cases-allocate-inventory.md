# Test Cases: Allocate Chipset Inventory to a Production Run

| Test Case ID | Title | Covers | Preconditions | Steps | Expected Result |
| --- | --- | --- | --- | --- | --- |
| TC-AllocateChips-01 | Run fully allocated from on-hand and incoming inventory | Basic Path | Every bill-of-materials chip has at least one approved-vendor-list entry with sufficient on-hand/incoming stock. | 1. Schedule a production run with a target quantity and start date. 2. Observe Continental ERP calculate required chip quantities. 3. Observe the inventory check and reservation. 4. Observe the constrained-chip allocation notice to the Sourcing Manager. 5. Release the run. | Continental ERP shows the run as fully allocated, with reserved-inventory records for every required chip tied to the run, and the Assembly Line's work queue includes the run. |
| TC-AllocateChips-02 | Two approved suppliers tie on available stock for the same chip | Alternate Path A | Same as TC-01, plus two approved-vendor-list suppliers each independently have enough stock for the same required chip. | 1. Schedule a run where two suppliers tie on available stock for one chip. 2. Observe which supplier's lot gets reserved. | The chip is reserved from the supplier with the nearer lot expiration; the use case proceeds to complete allocation as in the Basic Path (rejoins at Basic Path #4). |
| TC-AllocateChips-03 | Shortage resolved by expediting an approved supplier | Exception Path A | Same as TC-01, except on-hand plus incoming inventory for one required chip falls short of the run's quantity. | 1. Schedule a run with a known shortfall on one chip. 2. Observe the run flagged as partially allocated and the Sourcing Manager notified. 3. Sourcing Manager expedites stock from an approved supplier. 4. Observe Continental ERP re-check inventory. | The chip's shortfall is closed and the run proceeds to full allocation as in the Basic Path (rejoins at Basic Path #3); no test coverage needed beyond the point of rejoin for this test case. |
| TC-AllocateChips-04 | Shortage unresolved before the run's start date | Exception Path B | Same as TC-AllocateChips-03, except no approved or newly qualified supplier can close the gap in time. | 1. Schedule a run with a shortfall no supplier can resolve before the start date. 2. Observe the Sourcing Manager's notification to the Production Planner. 3. Reduce the run's quantity or reschedule the start date. | A revised run record exists at a reduced quantity, a later start date, or both, with no reserved-inventory record for the un-covered chip; the original quantity and start date are not carried forward. |
