# Test Cases: Qualify a New Chipset Supplier

| Test Case ID | Title | Covers | Preconditions | Steps | Expected Result |
| --- | --- | --- | --- | --- | --- |
| TC-QualifySupplier-01 | Candidate supplier approved on first submission | Basic Path | Component category is defined in Continental ERP; sourcing policy is configured. | 1. Submit a qualification request for a candidate supplier and component category. 2. Submit complete fab-location, ECCN, and capacity documentation. 3. Observe Compliance Officer's review and approval. | The approved-vendor list contains a new entry linking the supplier and its part number(s) to the component category, and the supplier is selectable in production-run allocation. |
| TC-QualifySupplier-02 | Candidate resubmits after incomplete documentation | Alternate Path A | Same as TC-01, except the initial submission omits export-control classification. | 1. Submit a qualification request. 2. Submit documentation missing ECCN. 3. Observe Continental ERP's request for the missing item. 4. Submit the missing ECCN documentation. 5. Observe Compliance Officer's review and approval. | Same as TC-01: the approved-vendor list contains the new entry once the complete documentation is reviewed and approved (rejoins at Basic Path #4). |
| TC-QualifySupplier-03 | Candidate rejected for out-of-policy fab location | Exception Path A | Same as TC-01, except the candidate's documentation shows a fab outside the U.S./EU. | 1. Submit a qualification request. 2. Submit documentation showing a non-U.S./EU fab. 3. Observe Compliance Officer's rejection. 4. Observe the notification to the Sourcing Manager. | The qualification case is recorded as rejected with the specific policy reason; the approved-vendor list is unchanged and the supplier is not selectable in allocation. |
| TC-QualifySupplier-04 | Candidate does not respond before the documentation deadline | Exception Path B | Same as TC-01, except the candidate never submits documentation. | 1. Submit a qualification request. 2. Allow [DOCUMENTATION_DEADLINE] to pass with no submission. 3. Observe Continental ERP mark the case stalled. 4. Observe the notification to the Sourcing Manager. | The qualification case is recorded as stalled or closed; the approved-vendor list is unchanged. |
